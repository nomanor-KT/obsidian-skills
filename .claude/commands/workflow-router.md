Na podstawie zadania użytkownika wybierz najlepszy tryb wykonania.

## Reguły decyzji

1. Command
- Gdy zadanie jest powtarzalne, krótkie i ma stały schemat.
- Przykład: briefing, check lista, szybka walidacja.

2. Skill
- Gdy potrzebna jest wiedza domenowa i konkretne standardy jakości.
- Przykład: architektura, review PR, runbook, onboarding.

3. Agent/Subagent
- Gdy zadanie jest szerokie, eksploracyjne albo wieloetapowe.
- Przykład: duży research, analiza wielu katalogów, porównania opcji.

## Output

Podaj:
1. Wybrany tryb: Command / Skill / Agent
2. Uzasadnienie w 2-3 zdaniach
3. Konkretną komendę lub skill do uruchomienia
4. Największe ryzyko wyboru
